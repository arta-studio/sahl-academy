# أكاديمية سهل ستور

منصة كورس «حوّل المنهج إلى لعبة».

- الواجهة: HTML + JavaScript بدون أدوات بناء، منشورة على GitHub Pages.
- الحسابات وقاعدة البيانات والفيديوهات المحمية: Supabase (`supabase/schema.sql`).
- الإعدادات (رقم الواتساب، السعر، اسم الكورس): `config.js`.

## إدارة المشتركين
1. المشترك يسجّل من الموقع.
2. يدفع عبر الواتساب.
3. من «لوحة الإدارة» ← «المشتركين» اضغط «تفعيل».

## رفع درس جديد
لوحة الإدارة ← «المحتوى» ← «رفع فيديو» و«إضافة ملحق». لإضافة درس جديد أضف صفاً في جدول `lessons` من Supabase.
